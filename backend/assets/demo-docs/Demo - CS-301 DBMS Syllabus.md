# CS-301 Database Management Systems — Course Syllabus (demo document)

Course code: CS-301 · Credits: 4 (3 lecture + 1 lab) · Semester 5, B.Tech Computer Science and Engineering

## Course outcomes
1. Model an application domain with entity–relationship diagrams.
2. Write SQL queries with joins, grouping, sub-queries and views.
3. Normalise relations up to Boyce–Codd normal form (BCNF).
4. Explain transactions, concurrency control and recovery.
5. Compare indexing structures such as B+ trees and hashing.

## Units
- Unit 1: Introduction, data models, three-schema architecture.
- Unit 2: ER model, relational model, relational algebra.
- Unit 3: SQL — DDL, DML, constraints, views, triggers.
- Unit 4: Functional dependencies, normal forms (1NF, 2NF, 3NF, BCNF), decomposition.
- Unit 5: Transactions, ACID properties, serializability, two-phase locking, logging and recovery.
- Unit 6: File organisation, B+ tree indexes, hashing, query processing basics.
